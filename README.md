# 🌟 Personal Portfolio Website

A modern and fully responsive personal portfolio website built using **React.js**, **Vite**, and **Tailwind CSS**. This portfolio showcases my skills, projects, education, and professional profile with an attractive and interactive user interface.

## 🚀 Live Demo



---

## 📌 Features

- Responsive design for all devices
- Smooth scrolling navigation
- Interactive UI with modern animations
- Typewriter text effect
- Parallax tilt profile image
- Skills showcase section
- Project gallery with detailed modal view
- Education timeline
- Download Resume button
- Social media integration
- Clean and modern design

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Libraries Used
- React Icons
- React Simple Typewriter
- React Parallax Tilt

## 📖 Sections Included

### 👋 About
Introduction, professional summary, and downloadable resume.

### 💻 Skills
Showcases frontend, backend, database, and development tools.

### 🚀 Projects
Displays project cards with:
- Project Image
- Description
- Technologies Used
- GitHub Repository
- Live Demo Link

### 🎓 Education
Timeline-based education section highlighting academic background.

### 📞 Footer
Quick navigation links and social media profiles.
